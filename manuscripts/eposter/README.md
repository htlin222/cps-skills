# WCIM 2026 E-Poster

One-page A4 e-poster for the 38th World Congress of Internal Medicine
(Taipei, 2026), built from the case material in this repository.

**Output:** `eposter.pdf` — A4 portrait, 1 page, ~170 KB, Arial-metric fonts embedded.

## Build

```bash
./build.sh                          # bundled vector letterhead
./build.sh ~/wcim-template.png      # official WCIM template artwork
```

`build.sh` renders `eposter.html` through headless Chromium and then checks the
congress requirements (single page, A4, under 5 MB).

## Files

| File | Purpose |
|------|---------|
| `eposter.html` | The poster. All content and layout live here. |
| `assets/wcim-bg.svg` | Vector reconstruction of the WCIM 2026 letterhead. |
| `assets/bg-override.css` | Generated by `build.sh` when an official template is supplied. |
| `render.mjs` | HTML → PDF via Chromium DevTools Protocol; reports column overflow in mm. |
| `build.sh` | Wrapper: background selection, render, spec checks. |

## Replacing the letterhead

`assets/wcim-bg.svg` is a **reconstruction** drawn to match the congress
template, not the official artwork. When the official A4 template is available,
pass it to `build.sh`; it is layered under the same content box, so nothing else
needs to change.

The content box is inset 14 mm left/right, 30 mm from the top (clearing the logo
lockup) and 23 mm from the bottom (clearing the congress footer line).

## Content sources

Text and figures are drawn from `manuscripts/abstract/abstract.qmd`,
`manuscripts/poster/index.qmd`, and the case files under `case/`.

## Congress requirements

| Requirement | Status |
|-------------|--------|
| A4, 1 page | A4 portrait, single page |
| Arial / Times New Roman / Verdana | Liberation Sans (metrically identical to Arial) |
| ≤ 5 MB, PDF | ~170 KB PDF |
